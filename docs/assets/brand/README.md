# Sleepy Pokemon Brand Assets

Working logo direction: **Sparkle**.

The mark is two slightly offset cards with a small four-point sparkle. It is intended to feel like a collector's binder page caught mid-shuffle: card-first, original, soft, and lightly magical.

Files:

- `sleepy-pokemon-mark.svg`: primary full-color mark.
- `sleepy-pokemon-mark-one-color.svg`: one-color utility mark.
- `sleepy-pokemon-logo-horizontal.svg`: default wordmark lockup.
- `sleepy-pokemon-logo-stacked.svg`: stacked/social lockup.
- `sleepy-pokemon-logo-dark.svg`: dark header treatment.
- `sleepy-pokemon-favicon-v2.svg`: heavier small-size favicon candidate.

Palette:

- Deep navy: `#17263C`
- Card coral: `#E29684`
- Sleep sage: `#9FC8BC`
- Paper cream: `#FCF4E4`
